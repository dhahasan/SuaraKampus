Buatkan aplikasi mobile Flutter (Dart) bernama "SuaraKampus", portal aspirasi
dan menfess mahasiswa dengan moderasi admin. Tampilan HARUS persis mengikuti
desain Figma yang saya deskripsikan di bawah. Gunakan Material 3, null-safety,
dan Dart 3.x.

══════════════════════════════════════════
1. TECH STACK & ARSITEKTUR
══════════════════════════════════════════
- Flutter 3.x, Dart 3.x
- State management: Riverpod (flutter_riverpod + riverpod_annotation)
- Routing: go_router (dengan ShellRoute untuk bottom navigation)
- Model: freezed + json_serializable
- Backend: Firebase (Auth, Firestore, Storage) — buat abstraction repository
  agar mudah diganti, sediakan mock data lokal sebagai default
- Package tambahan: google_fonts, flutter_svg, image_picker, cached_network_image,
  fl_chart (atau custom painter) untuk grafik, intl, shimmer
- Struktur folder (feature-first):
  lib/
   ├─ core/ (theme, constants, widgets reusable, utils, router)
   ├─ features/
   │   ├─ splash/
   │   ├─ auth/ (login, register, verifikasi akun/KTM)
   │   ├─ feed/ (feed, detail, laporkan)
   │   ├─ compose/ (tulis menfess/aduan)
   │   ├─ riwayat/
   │   ├─ profil/
   │   └─ admin/ (moderasi, tindak lanjut, antrean instagram, statistik)
   └─ main.dart

══════════════════════════════════════════
2. DESIGN SYSTEM (WAJIB KONSISTEN)
══════════════════════════════════════════
Font: Plus Jakarta Sans (google_fonts). Ukuran: judul layar 16-18 bold,
judul kartu 13-14 semibold, body 11-12 regular, caption/badge 9-10.

Warna (definisikan di AppColors):
- primary / teal tua: #0E6B85 (tombol utama, ikon aktif, header splash)
- primaryDark: #0A5368
- background layar: #F3F9FC (biru sangat muda)
- surface kartu: #FFFFFF, border #D9E8EF, radius 12-14, shadow lembut
- infoBg: #E6F3F8 (kotak info biru muda)
- warningBg: #FFF6DC, warningBorder: #F5D98A, warningText: #8A6A00
- dangerRed: #D32F2F (tombol Hapus, badge URGENT, "Tolak" outline merah)
- dangerBg: #FDECEC
- success hijau: #2E9B5B, successBg: #E3F5EA (badge "Selesai", "Kecepatan Baik")
- orange/amber badge "Menunggu": #F59E0B dengan bg #FFF1D6
- teks utama: #12303B, teks sekunder: #6B8794
- Badge/chip: pill, radius 20, padding horizontal 8, vertikal 2-3.
- Tombol: tinggi 40-44, radius 10-12. Primary = filled teal; secondary =
  filled biru muda (#DCEEF5) teks teal; outline merah untuk aksi negatif.
- Input: border #D9E8EF radius 8, fill putih, label kecil di atas.
- Bottom nav: 4 item, ikon + label kecil, aktif teal, tidak aktif abu.
- Status bar jam "09:41" hanya di mockup, JANGAN ditampilkan di app asli.

Buat widget reusable: AppButton (primary/secondary/danger/outline),
AppBadge, AppCard, InfoBanner (info/warning/danger), CategoryChip,
SectionHeader, AppTextField, StatCard, ProgressBarRow, BottomNavShell.

══════════════════════════════════════════
6. ATURAN BISNIS
══════════════════════════════════════════
- Kuota 5 menfess/bulan per mahasiswa; saat habis form disabled.
- Hanya akun terverifikasi (email .ac.id + KTM disetujui) yang bisa
  menulis.
- Menfess baru berstatus "pending" sampai admin meloloskan.
- Deteksi sederhana nama orang/dosen → tampilkan warning kuning.
- Laporan ≥3 → otomatis masuk tab "Dilaporkan Civitas" (merah) di admin.
- Hanya menfess approved + allowInstagram yang masuk antrean IG.
- Role-based routing: admin diarahkan ke shell admin, mahasiswa ke shell
  mahasiswa.
